# Insurance Cost Prediction

## Project Overview
This project predicts medical insurance charges using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
The dataset contains:
- Age
- Gender
- BMI
- Number of Children
- Smoker Status
- Region
- Insurance Charges

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Encoding
5. Model Building
6. Model Evaluation
7. Feature Importance Analysis
8. Model Saving using Joblib

## Models Compared
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Best Model
Random Forest Regressor achieved the highest R² score and was selected as the final model.
